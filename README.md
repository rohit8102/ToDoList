# 📝 C++ To-Do List Application

A console-based To-Do List application developed using C++.

## 🚀 Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Task priorities
- Date and time tracking
- Persistent file storage
- Task statistics
- Colored console interface

## 🛠️ Technologies

- C++
- OOP
- STL Vector
- File Handling
- Windows Console API

## 💾 Data Storage

Tasks are stored locally using a TXT file.

## ▶️ How to Run

Compile:

```bash
g++ main.cpp -o todo.exe
